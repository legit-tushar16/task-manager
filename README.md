# Task Manager (Full-Stack)

## 🚀 Features
- User Authentication (Firebase Email/Password)
- Role-Based Access (Admin / Member)
- Admin can create tasks
- Members can update task status
- Real-time data using Firestore

## 🛠 Tech Stack
- React (Vite)
- Firebase Auth
- Firestore Database
- Vercel (Deployment)
